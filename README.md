# TextAnalyzerApp

Title: TextAnalyzerApp – .NET Desktop Application for Text Analysis

Description:
A C#/.NET application that analyzes text for word count, character frequency, and other metrics. Designed as a learning project to strengthen .NET fundamentals and demonstrate text processing, file I/O, and UI design.

Features:

Word count and character frequency analysis

Support for multiple file formats (e.g., TXT)

Simple, intuitive desktop interface

Error handling for empty or invalid inputs

Built with maintainable, clean code structure


Technologies Used:

C#

.NET Framework 7.0

WPF
